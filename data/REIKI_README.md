# 例規集のCMS管理について

例規集ページで表示するセクション・編・章・項目をJSONで管理するための説明です。

## ファイル構造

```
data/
  reiki.json              … 例規集・監査基準の全構造（CMSで編集）
  REIKI_README.md         … 本説明

other/
  reiki.html              … 例規集ページ
  reikiLoader.js           … JSONを読み込み一覧を描画・展開するスクリプト
```

## data/reiki.json の役割

- **CMSで編集する主なファイル**です。
- 例規集ページ（other/reiki.html）で表示する「１．例規集」と「２．監査基準」の2つのトップセクション、およびその中身（編・章・項目）を定義します。
- フロントはこのJSONを読み込み、展開可能なブロックとして動的に生成します。

### 各項目の意味

| 項目 | 説明 |
|------|------|
| sections | トップレベルセクションの配列（表示順） |
| sections[].title | セクションの見出し（例: 「１．志摩広域行政組合例規集」） |
| sections[].subtitle | セクション内のサブタイトル（任意） |
| sections[].hens | 「例規集」の場合のみ。編の配列（第1編～第8編など） |
| sections[].hens[].title | 編の見出し（例: 「第1編 総規」） |
| sections[].hens[].chapters | 章の配列 |
| sections[].hens[].chapters[].title | 章の見出し（例: 「第１章 組合設立」）。空の場合は見出しなしで項目のみ表示 |
| sections[].hens[].chapters[].items | その章内の項目（リンクラベル）の配列 |
| sections[].note | 「監査基準」など、補足文があるセクション用 |
| sections[].links | 「監査基準」など、リンクのみのセクション用。`label` と `href` の配列 |

### 例規集セクション（hens あり）の構造例

```json
{
  "title": "１．志摩広域行政組合例規集",
  "subtitle": "志摩広域行政組合例規集",
  "hens": [
    {
      "title": "第1編 総規",
      "chapters": [
        { "title": "第１章 組合設立", "items": ["規約", "休日を定める条例"] },
        { "title": "第２章 公告式", "items": ["公告式条例", "公告式規則"] }
      ]
    }
  ]
}
```

### 監査基準セクション（links あり）の構造例

```json
{
  "title": "２．志摩広域行政組合監査基準",
  "subtitle": "志摩広域行政組合監査基準",
  "note": "地方自治法（昭和22年法律第67号）第198条の4第1項の規定に基づき監査基準を策定しました。",
  "links": [
    { "label": "志摩広域行政組合監査基準（PDF）", "href": "" }
  ]
}
```

- `href` が空の場合は `#` として表示され、URLを指定すると別タブで開くリンクになります。

### 編・章・項目の追加・変更

- **編の追加**: `sections[0].hens` に新しいオブジェクト（`title` と `chapters`）を追加する。
- **章の追加**: 該当編の `chapters` に `{ "title": "第○章 ○○", "items": ["…"] }` を追加する。
- **項目の追加**: 該当章の `items` 配列に文字列を追加する。
- 現状、例規集内の項目リンクはすべて `href="#"` です。必要に応じてJSONに `href` を持たせ、ローダー側で反映するよう拡張できます。

## 表示との連携

- 例規集ページ（other/reiki.html）では、**reikiLoader.js** がこのJSONを読み込み、`#reikiListContainer` 内に展開可能なHTMLを生成します。
- 「１．例規集」を開くと各編が表示され、編をクリックすると章・項目が展開されます。
- JSONを編集して保存すると、次回のページ表示で内容が反映されます。
