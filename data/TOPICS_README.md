# お知らせ（トピックス）のCMS管理について

トップページ・お知らせページで表示するお知らせ一覧をJSONで管理するための説明です。

## ファイル構造

```
data/
  topics.json             … お知らせの一覧データ（CMSで編集）
  TOPICS_README.md        … 本説明

js/
  topicLoader.js          … お知らせページ用（topic.html で使用）
  sliderLoader.js         … トップページスライダー用（index.html で使用）
```

## data/topics.json の役割

- **CMSで編集する主なファイル**です。
- お知らせ（トピックス）の一覧を配列で保持し、トップページのスライダーやお知らせページの一覧表示で参照されます。
- 各要素は「日付・タイトル・カテゴリ・説明・画像」などを含みます。

### 各項目の意味

| 項目 | 説明 |
|------|------|
| （配列の各要素） | 1件のお知らせ |
| id | 識別用ID（数値） |
| date | 表示用日付（例: "2011-04-01"） |
| title | お知らせのタイトル |
| category | カテゴリ（例: 「お知らせ」「求人」「入札」） |
| description | 説明文（任意） |
| image | 画像パス（任意。空の場合は画像なし） |

### お知らせの追加手順

1. **data/topics.json** の配列に、新しいオブジェクトを追加する。
2. `id` は既存の最大IDより大きい数値にする（重複しないこと）。
3. `date`・`title`・`category` を必須で指定し、`description`・`image` は必要に応じて指定する。

```json
{
  "id": 100,
  "date": "2025-02-01",
  "title": "新着お知らせのタイトル",
  "category": "お知らせ",
  "description": "",
  "image": ""
}
```

### お知らせの並び順

- 配列の並びがそのまま表示順になります。新しいお知らせは配列の先頭に追加するか、日付でソートする処理をローダー側で行うとよいです（現状はJSONの並びのまま表示）。

## 表示との連携

- **topic.html**（お知らせページ）では **js/topicLoader.js** が `data/topics.json` を読み込み、一覧を描画します。
- **index.html**（トップページ）では **js/sliderLoader.js** が同じJSONを参照し、スライダー用のコンテンツを組み立てます。
- JSONを編集して保存すると、次回のページ表示で内容が反映されます。
